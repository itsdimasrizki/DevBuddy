Common developer onboarding questions — instant answers.

Q How do I set up my local dev environment?
A Run make setup from the repo root. It installs dependencies, seeds the local DB, and starts all services via Docker Compose. Full guide in docs/setup.md.
Q What’s the branching strategy?
A We use GitHub Flow. Branch from main, prefix with feat/, fix/, or chore/. Open a PR for review — at least 1 approval required before merge.
Q How do I run tests locally?
A Use pnpm test for unit tests and pnpm test:e2e for end-to-end. Coverage reports are generated in /coverage. CI enforces ≥80% coverage.
Q Who do I contact for access issues?
A Ping #it-access on Slack for GitHub/GitLab permissions. For cloud console access, raise a Jira ticket in the INFRA project with your buddy tagged.
